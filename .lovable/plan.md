# خطة التنفيذ — تطوير المنصة لمستوى MVP حقيقي

سأنفذ الخطوات الثلاث التي اتفقنا عليها بالترتيب، بحيث تكون كل مرحلة مكتملة ومستقلة قبل الانتقال للتالية.

---

## المرحلة 1️⃣ — نظام المصادقة وملف المستخدم

**الهدف:** تمكين المستخدمين من التسجيل وحفظ نتائجهم.

- تفعيل المصادقة بـ **البريد + كلمة المرور** و **جوجل**
- إنشاء جدول `profiles` مرتبط بـ `auth.users` (الاسم، العمر، المرحلة الدراسية/المهنية، البلد)
- إنشاء جدول `user_roles` منفصل (student / professional / admin / coach) لحماية الصلاحيات
- صفحات: `/auth` (تسجيل دخول + إنشاء حساب)، `/profile` (الملف الشخصي)
- ربط Header بحالة المستخدم (تسجيل دخول / خروج / صورة)
- حماية الصفحات الحساسة بـ `_authenticated` layout

---

## المرحلة 2️⃣ — حفظ نتائج التقييمات وربطها بالمستخدم

**الهدف:** كل تقييم يقوم به المستخدم يُحفظ في حسابه ويمكن مراجعته لاحقاً.

- إضافة عمود `user_id` (nullable) لجداول التقييمات الموجودة:
  - `assessment_reports`, `clarity_scores`, `wellbeing_screenings`, `development_plans`
- تحديث RLS:
  - مجهولون: يمكنهم القراءة بالكود (السلوك الحالي يبقى)
  - مسجلون: يرون كل تقييماتهم تلقائياً
- صفحة `/my-assessments` تعرض سجل التقييمات للمستخدم مع التواريخ
- زر "تحميل التقرير PDF" لكل تقييم (تجميع بسيط HTML→Print)

---

## المرحلة 3️⃣ — تحليل ذكي بـ AI (Lovable AI Gateway)

**الهدف:** تقرير شخصي ذكي بدلاً من نتائج ثابتة، باستخدام `google/gemini-2.5-flash` (مجاني عبر Lovable AI).

- إنشاء `createServerFn` باسم `generateAIReport` تستقبل إجابات التقييم
- استدعاء Lovable AI Gateway بـ system prompt متخصص بالإرشاد المهني العربي
- إخراج: نقاط القوة، التحديات، 3 مسارات مهنية مقترحة، خطة 90 يوم
- حفظ التقرير في `assessment_reports.report` (الحقل موجود بالفعل)
- صفحة عرض التقرير بتنسيق احترافي قابل للطباعة

---

## التفاصيل التقنية (للمراجعة)

- **Stack:** TanStack Start + Supabase (Lovable Cloud) + Lovable AI Gateway
- **Auth:** Email/Password + Google OAuth (عبر Lovable broker)
- **AI Model:** `google/gemini-2.5-flash` (سريع ومجاني حالياً)
- **RLS:** كل الجداول الحساسة محمية، الجداول العامة تبقى كما هي
- **Roles:** جدول منفصل + دالة `has_role()` SECURITY DEFINER لتجنب recursion
